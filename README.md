# 🤪 Funny AutoCorrect Everywhere (FACE)

**Funny AutoCorrect Everywhere (FACE)** is a zero-configuration, automated browser extension designed to inject pure chaos into your daily typing. It automatically intercepts common English words you type across any webpage and dynamically swaps them with look-alike comic alternatives that sound similar but carry entirely unhinged meanings.
